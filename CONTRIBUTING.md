# Contributing to the New Data Sources handbook

Thank you for your interest in contributing to the handbook! With your help, we can ensure the handbook valuable to all price statistics practioners implementing new data sources. There are many ways you can help.

Example contributions:
* minor changes or fixes (e.g. fix spelling, bolster a piece of guidance iwth a useful reference)
* moderate changes (e.g. improve how a method or practice is described, add a notebook showing how to solve a specific step through code)
* propose or collaborate in contributing major improvements (e.g. outline a new section on something that was missing, add a recommendation on topics to document)

# How to contribute

The easiest way to contribute is to add an issue with your idea. We will discuss the idea with you and invite you to support it further, such as by submitting a Pull Request. Detailed overview on [how to contribute](https://un-task-team-for-scanner-data.github.io/cpi-new-data-sources-handbook/about/contributing.html) is available on the project site.

# Code of Conduct

As a contributor, help keep the community open, inclusive, and collaborative. Read the [code of conduct](/CODE_OF_CONDUCT.md) for more details.

# Quick tips on the repository structure

If you are making consequential changes (such as adding new materials), please keep the following structure in mind and add your files to the relevant folder.

```
├── handbook                # Where main handbook content is stored
│   ├── images              # Folder where all images and files that generate images (such as 
│   │                         draw.io files) are stored (in sub-folders)
│   └── *                   # Grouped content (such as classification) is grouped into a sub-folder
│
├── training                # Where the overview of training materials is stored
│
├── notebooks               # Where notebooks with code examples are stored
│
└── about                   # Where administrative project pages are stored

```
