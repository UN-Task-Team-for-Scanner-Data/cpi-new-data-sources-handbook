## What is the handboook?

Are you a price statistician that is looking to learn more about new (i.e. alternative) data sources for consumer price statistics, research something specific that would use this data, or partake in efforts to improve price statistics with this data? This handbook is meant for you! This handbook is a trustworthy neutral summary of practices and research on various technical, methodological, an operational aspects of alternative data.

## Where to find the handbook?

This repository hosts the handbook  -- see [project site](https://un-task-team-for-scanner-data.github.io/cpi-new-data-sources-handbook/) for more details.
